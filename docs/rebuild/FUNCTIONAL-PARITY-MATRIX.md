# Paridad funcional

`P` indica preservación en el código actual. `I` indica una mejora de esta rama. `V` indica prueba dirigida recogida en el informe de pruebas. Las filas agrupan acciones que comparten pantalla y contrato.

| Área y ruta | Vistas y acciones | Datos y autorización | Resultado y evidencia |
| --- | --- | --- | --- |
| Sitios · `/studio/settings/sites` | Sitios, destino, edición, sitio activo y borrado | `GET/PUT/DELETE /v2/sites`, sesión activa, escritura con `integrations.manage` | I/V. Carga y reintento, verificación guardada, confirmación, errores y edición persistida en navegador. SSR verificó la actualización del inventario con un backend de prueba. Identidad editorial y marca se gestionan en Escritura, el wizard y Site Intelligence. |
| Escritura · `/studio/settings/writing` | Instrucciones, estructura/enlaces, visuales, CTA, negocio, marca/aviso | `GET/PUT /v2/sites/:id/planning-settings`, `projects.manage` para guardar; valores de sitio más ajustes de la pieza | I/V. Aislamiento de dos sitios y persistencia en navegador. API → redactor controlado → QA verificados para borradores manuales y guías planificadas. Las plantillas delimitan los bloques disponibles. Pendiente aceptación con servicios reales de medios y publicación. |
